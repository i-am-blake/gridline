# Gridline

**Ride the beat. Chase the sun.**

A neon, music-driven riding game in a single HTML file. The sky, sun, grid and trail react to the music; obstacles arrive on the beat; the road speed is locked to the tempo.

- Vehicles: light bike, hoverboard, dune buggy — each with its own strengths
- Worlds: Sunset Grid, Neon City, Endless Void
- Beats: Synthwave, Lo-fi, or your microphone
- Jumps, flips, tunnels, combos, gas and checkpoints
- Chapters every 5 levels: new sky, new obstacles (patrol robots, beat lasers, split roads), a gauntlet, rewards and weather

Open `gridline.html` in a browser to play. Controls: ← → steer · Space jump · ↓ backflip · ↑ front flip · P pause.
